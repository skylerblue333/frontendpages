# Documentation review

The `/documentation` route renders only a generic `FeatureUnavailable` placeholder. It provides no document catalog, article content, authorship, version history, search, navigation, access policy, publication, feedback, analytics, or persistence contract.

The safe replacement should provide a typed, accessible documentation-readiness view that explains the required content source, provenance, versioning, search index, permissions, review, publication, and feedback boundaries without fabricating technical guidance or operational documentation. Search, article opening, publishing, exporting, and feedback actions should remain explicit local no-ops.
