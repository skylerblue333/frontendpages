# DMInbox visual checkpoint

The route `/d-m-inbox` was verified in the direct Vite client. It renders a responsive messaging preview with local sample conversations, a search field, thread selection, an explicit provider boundary, unavailable presence and encryption status, and a local-only draft composer. Sample data is clearly labeled and states that no message has been delivered.

A local draft, `Test local draft only`, was entered and submitted with Enter. The draft remained in the composer and the route reported: `Message delivery is unavailable locally. No message, notification, AI, financial, media, or account mutation was started.`
