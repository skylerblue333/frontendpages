# DerivativesTrading review

The `/derivatives-trading` route is an explicit coming-soon placeholder. It presents no actual data or controls, but the route name is a high-risk financial surface where a future implementation must not imply market connectivity, leverage, order execution, positions, margin, PnL, liquidation, or settlement without verified providers and transaction contracts.

The safe replacement should turn the placeholder into a financial-readiness preview that labels market data, instrument definitions, risk controls, account authorization, order simulation, execution, margin, custody, monitoring, and reconciliation as unavailable. All order, refresh, connect, and trade actions should be explicit no-ops.
