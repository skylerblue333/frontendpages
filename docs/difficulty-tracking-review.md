# DifficultyTracking review

The `/difficulty-tracking` route is an explicit coming-soon placeholder. It presents no actual data or controls, but the route name is a high-risk mining and network-data surface where a future implementation must not imply network connectivity, difficulty history, hash rate, block timing, mining rewards, profitability, wallet balances, or forecasts without verified providers and provenance.

The safe replacement should turn the placeholder into a mining-readiness preview that labels network data, worker telemetry, rewards, profitability, wallet reconciliation, and prediction as unavailable. Refresh, calculate, connect, and export actions should be explicit no-ops.
