# DMInbox review

The `/d-m-inbox` route currently renders sample conversations and local message composition. It also presents Hope AI signal-reading language, presence, verification badges, encryption indicators, voice and video calls, image uploads, emoji, voice messages, token tips, and message delivery as interactive concepts.

The safe replacement must keep conversation data clearly labeled as local layout samples. It must not fabricate real users, presence, encryption, AI inference, token balances, tips, calls, uploads, delivery, or notification outcomes. Message composition can remain a local draft only; sending must be a no-op with an explicit unavailable status. AI actions must not claim to analyze signals or produce real replies.
