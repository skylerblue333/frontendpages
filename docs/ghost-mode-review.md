# GhostMode review

The `/ghost-mode` route currently presents hard-coded ghost identities, browser and timezone fingerprints, behavioral noise, notification controls, session rotation, identity generation, and success toasts. These are security and privacy-sensitive capabilities that require verified browser isolation, consent, threat modeling, auditability, and safe platform controls.

The safe replacement is a strictly typed local privacy-readiness view. Preserve the conceptual controls as previews, but label identity spoofing, fingerprint changes, notification interception, session rotation, random identity generation, stealth behavior, and persistence unavailable. No claim of anonymity, evasion, or security protection should be made.
