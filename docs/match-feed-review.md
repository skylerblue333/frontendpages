# MatchFeed review

The `/match-feed` route currently renders named match profiles, ages, online state, verification badges, message snippets, unread counts, conversation stages, compatibility percentages, and engagement scores. It links into dating chat routes and presents an unsupported claim that high-compatibility matches are three times more likely to respond within an hour.

These are unverified identity, presence, communication, recommendation, and behavioral analytics claims. The safe replacement should preserve search and filter concepts as local UI state only, use abstract conversation concepts rather than real-looking people or messages, remove response-rate claims, and block chat navigation, notifications, and match mutations with explicit unavailable statuses.
