## Integration requirements

The UI must **not** be copied verbatim into production. Before acceptance:

- verify every `aiCodeEngineer.*` procedure exists in the canonical gateway/backend contract;
- replace `any` result handling with explicit shared response types;
- add loading, error, empty, cancellation, and retry states using canonical frontend primitives;
- add accessibility checks for tabs, editors, generated output, and keyboard navigation;
- add unit/component coverage for each of the seven workflows;
- ensure generated code is displayed safely and never executed implicitly in the browser;
- enforce request size/time limits and authentication at the gateway;
- preserve the original source SHA in the migration record;
- run the existing frontend CI gates before acceptance.
