# Matchmaking review

The `/matchmaking` route is an explicit placeholder that only says the feature is coming soon. It needs a professional readiness view rather than an empty placeholder, while avoiding fabricated people, recommendations, compatibility, safety, or match outcomes.

The safe replacement should show the required stages of a responsible matchmaking flow: consent, profile completeness, privacy controls, safety and moderation, explainable recommendations, user feedback, and deletion. No matching job, profile lookup, score, recommendation, notification, or match creation should be performed locally.
